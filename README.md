<h1>AI-Based Sugarcane Disease Detection</h1>

Description:-This project is a Machine Learning based Sugarcane Disease Detection System. 
It uses CNN models to identify diseases from leaf images and helps farmers 
take early action.

Features:- <br>
- Detect sugarcane leaf diseases using images <br> 
- Built using CNN (Convolutional Neural Network)<br>  
- Accurate and fast prediction system <br> 
- User-friendly interface (Django based web app) <br>
- Image upload and instant result display

Tech Stack:-
- Programming Language: Python  
- Framework: Django  
- Deep Learning: Convolutional Neural Networks (CNN)
- Libraries: OpenCV, NumPy, TensorFlow / Keras, Matplotlib  
- Frontend: HTML, CSS, JavaScript
